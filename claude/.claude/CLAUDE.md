## How to explain things to me
- Relate new concepts to math, stats, ML, optimization, or CS fundamentals when a good analogy exists.
- In my weak areas, give the mental model first (what problem it solves and where it sits in the stack), then the specifics. Point out security pitfalls without being asked.
- In my strong areas, skip the basics and be precise.
- If you're unsure how much I know, give a short answer and offer to go deeper.

## Herdr agent names
- To name a Herdr agent (including yourself), run `herdr-name <name> [pane-id]` — not `herdr agent rename`, which doesn't survive Herdr restarts. `herdr-name --list` shows saved names.
